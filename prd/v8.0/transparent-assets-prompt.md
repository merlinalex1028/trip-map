# v8.0 透明背景聚合切图提示词

## 需要独立透明切图的资源

### 必须独立切图

1. **粉发旅行少女角色组**
   - 落地页主视觉：站立、拿相机、半身到全身，适合放在 hero 右侧。
   - 地图弹窗角色：半身、拿相机、面向用户，适合放在地点识别 popup 右侧。
   - 留下足迹弹窗角色：眨眼/开心、双手合起、旁边有白猫和花草，适合放在日期弹窗左侧。
   - 侧边栏底部角色 A：坐姿、拿相机、旁边有白猫、花草和“下一站”木牌。
   - 侧边栏底部角色 B：坐姿、拿旅行手账/笔记本、旁边有白猫、花草和“下一站”木牌。
   - 小头像/用户卡片头像：圆形裁切友好的粉发少女 bust portrait。

2. **猫咪品牌与吉祥物**
   - 线稿猫头 logo，粉色描边，可作为“旅记”图标。
   - 白色小猫正面坐姿。
   - 白色小猫趴姿/探头姿势，用于落地页和侧边栏装饰。

3. **地图与时间节点标记**
   - 粉色星星地图 pin。
   - 紫色星星地图 pin。
   - 蓝色星星地图 pin。
   - 橙色星星地图 pin。
   - 发光定位点。
   - 时间轴圆形星星节点：粉、紫、蓝、橙四种。

4. **功能插画图标**
   - 粉色立体星星图标，用于世界足迹/地图探索。
   - 紫色旅行手账本/日记本图标。
   - 蓝色相机图标。
   - 橙粉色奖章/徽章图标。
   - 紫色行李箱图标。
   - 旅行路牌/方向牌图标。
   - 地图定位 pin 图标。
   - 蓝色地球图标。

5. **木牌与旅行贴纸**
   - 落地页右侧竖向木牌组，4 个木质箭头牌，不带文字或文字可替换。
   - 小型“下一站”木牌，最好生成无文字版和带“下一站”版各一份。
   - 拍立得旅行卡片/明信片贴纸：东京/巴黎/巴厘岛/上海风景各一张，白色拍立得边框，轻微倾斜。
   - 旅行路线虚线和小节点贴纸，可用于落地页 hero。

6. **氛围装饰贴纸**
   - 四角星/闪光星星，粉、紫、黄、蓝多色。
   - 樱花花瓣散落贴纸。
   - 粉色樱花枝局部贴纸。
   - 小花丛/草地花朵边角贴纸。
   - 柔软云朵贴纸。
   - 猫爪印贴纸。
   - 小泡泡/光点贴纸。

### 不建议做透明切图

- 地图底图、省市边界、地图文字：用 Leaflet / GeoJSON / CSS 主题处理。
- 统计图表：用 ECharts 渲染，不要切静态图。
- 卡片、弹窗、按钮、侧边栏背景：用 CSS + shadcn-vue 组件实现。
- 页面文字、导航文字、数字：必须用真实 HTML 文本。
- 收藏爱心/收藏按钮：v8.0 已明确不做收藏功能，不要生成独立收藏图标。
- 旅途照片缩略图：如果需要，可以另行生成矩形 WebP/JPG，不属于透明贴纸资源。

所有元素都要是独立贴纸风格，彼此之间留足空隙，方便后续手动切出单个 PNG。  

画布规格：4096x4096 或更大，透明背景，PNG。  
排版方式：网格排列，每个资源单独占一个区域，元素之间至少 120px 间距，不要互相重叠，不要被裁切。

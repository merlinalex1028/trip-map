# v8.0 PNG 切图指南

你现在只有 5 张完整页面 PNG，所以切图要分清两件事：

1. **从截图里裁剪原始素材**：得到 `raw crop`。
2. **把 raw crop 处理成可用透明素材**：抠背景、补边缘、去文字、导出 WebP/PNG。

不要直接把完整页面截图塞进前端当背景。那样看起来接近，但页面会失去真实交互、响应式和数据绑定。

## 推荐工具

### 最推荐：Photopea / Photoshop

适合角色、猫、木牌、花草这类复杂抠图。

关键功能：

- `Select Subject` / `Remove Background`
- Layer Mask，不要用橡皮擦直接删
- `Select and Mask`
- `Decontaminate Colors`
- `Generative Fill` 或修补工具去掉背景残留

### 轻量方案：Figma

适合先画切片框、导出 raw crop、管理命名。

缺点：Figma 抠复杂透明边缘不如 Photoshop。

### 自动抠图工具

适合快速初稿：

- remove.bg
- Photoshop Remove Background
- `rembg`

自动抠图之后仍然要人工检查边缘，尤其是粉色头发、白猫、花草和浅色背景之间容易粘连。

## 切图总流程

### 1. 建立切片文件

在 Figma 或 Photoshop 中建立一个文件：

```text
v8-slicing
  page-landing: 放入 落地页.png
  page-map: 放入 世界足迹.png
  page-footprint-dialog: 放入 留下足迹.png
  page-journal: 放入 旅途手帐.png
  page-memories: 放入 旅途回忆.png
```

每张图保持原始尺寸，不要缩放。

### 2. 给每个素材画 Frame / Slice

切片边缘至少留：

- 角色：30-60px 透明余量
- 小图标 / pin：12-24px 透明余量
- 贴纸 / 木牌：20-40px 透明余量
- 卡片缩略图：可以不留透明余量，按矩形裁切

不要贴着边缘切，否则后续 hover 放大、drop-shadow、呼吸动画会被裁掉。

### 3. 先导出 raw crop

raw crop 命名建议：

```text
raw-crops/landing-hero-girl.raw.png
raw-crops/map-popup-girl.raw.png
raw-crops/footprint-dialog-girl.raw.png
```

raw crop 允许带背景，因为它只是中间产物。

### 4. 抠透明背景

复杂素材处理顺序：

1. 自动选择主体。
2. 转为 Layer Mask。
3. 进入边缘优化，羽化 `0.5-1px`。
4. 边缘向内收缩 `1px`，减少白边/粉边。
5. 在透明背景下检查。
6. 在深色、浅色、粉色三种底色上各检查一次。
7. 导出透明 PNG 或透明 WebP。

角色头发、猫毛、花草边缘要宁可保守一点，不要抠出锯齿。

### 5. 去掉截图中的文字或 UI 残留

如果素材上带了不应该保留的文字，比如木牌文字、卡片文字：

- 如果这个文字未来不需要改，可以暂时保留作为装饰图。
- 如果文案要由前端控制，就不要用这张切图，应该重新生成无字版。
- 不要在前端用 CSS 覆盖图片里的文字，这会很脏，也不响应式。

### 6. 导出格式

| 类型 | 推荐格式 | 原因 |
|------|----------|------|
| 角色、猫、花草、木牌 | WebP 透明 或 PNG 透明 | 有复杂半透明边缘 |
| 小 pin / 节点 | PNG 透明 | 需要清晰边缘和发光 |
| logo | SVG 优先，PNG 备用 | 可缩放 |
| 旅行缩略图 | WebP/JPG | 不需要透明，体积更小 |
| 光点/星星 | SVG 或 PNG sprite | 很多可以直接用 CSS/SVG |

## 每张 PNG 的切图建议

### `落地页.png`

适合切：

| 素材 | 建议切法 |
|------|----------|
| 右侧粉发 hero 少女 | 从人物完整外轮廓外 40px 裁 raw crop，再抠透明。注意右侧樱花和背包边缘。 |
| 右侧木牌组 | 如果保留图片中文字，可直接抠成装饰；如果要改文案，需要重新生成无字版。 |
| 木牌上的小猫 | 单独裁切，抠透明，注意和木牌接触的阴影。 |
| 拍立得旅行卡片 | 可矩形裁切；如果要保留拍立得边框，按白边外 12px 切。 |
| hero 中间旅行路线小卡片 | 不建议当 UI 组件用，可作为氛围贴纸临时使用。 |
| 顶部樱花枝 | 不建议从截图硬抠，背景融合太重；建议重新生成透明贴纸。 |

不适合切：

- 大标题、副标题、按钮、功能卡片、统计数字、底部 CTA。
- 整张背景，因为里面混有角色、文字、卡片和 UI。

如果想得到干净落地页背景：需要用 Photoshop Generative Fill / 图像生成把文字、按钮、卡片、角色、木牌移除，补成“天空 + 山水 + 樱花 + 远景”的纯背景。

### `世界足迹.png`

适合切：

| 素材 | 建议切法 |
|------|----------|
| 地图 popup 少女 | 从 popup 右侧少女外轮廓裁切，再抠透明。因为人物背后是白色 popup，边缘会比较好抠。 |
| 侧边栏坐姿少女 + 猫 + 花草 + 木牌 | 可以作为一个组合切图，适合侧边栏底部。 |
| 星形地图 pin | 分别裁北京、西安、上海、广州 pin。每个 pin 用正方形画布，保留发光外扩。 |
| 用户头像 | 可以裁圆形头像，也可以保留圆形背景。 |
| 猫头 logo | 可裁后矢量化。 |

不适合切：

- 地图底图、省市文字、海岸线、popup 卡片、导航菜单。
- “我的收藏”图标和入口，v8.0 不做收藏。

地图背景应该由 Leaflet/GeoJSON 渲染，再用 CSS filter 和配色接近设计稿。

### `留下足迹.png`

适合切：

| 素材 | 建议切法 |
|------|----------|
| 左侧少女 + 白猫 + 花草 | 建议作为一个组合切图，保留底部花草完整。 |
| 少女单体 | 如果之后想在其他页面复用，可再单独抠一版。 |
| 白猫 | 可以从组合里单独裁一版，但边缘要人工修。 |
| 小爪印 / 星星 | 可切，但很多可以用 SVG/CSS 替代。 |

不适合切：

- 弹窗框、日历、日期数字、快捷按钮、底部按钮。

这些必须由 shadcn-vue Dialog/Calendar 和真实 HTML 实现。

### `旅途手帐.png`

适合切：

| 素材 | 建议切法 |
|------|----------|
| 侧边栏拿手账少女 + 猫 + 木牌 | 可作为组合切图，用在手账/回忆页面左下角。 |
| 时间轴星形节点 | 可裁 pink/purple/blue 三种节点，保留外圈光晕。 |
| 旅行缩略图 | 河源、京都、巴黎、上海等可按矩形裁切成 WebP。 |
| 用户头像 | 可复用或裁一版不同表情。 |

不适合切：

- “添加新旅行”按钮，因为本轮明确不要。
- 收藏爱心/星标按钮，因为本轮明确不要收藏功能。
- 时间线竖线和卡片，这些用 CSS 实现。

### `旅途回忆.png`

适合切：

| 素材 | 建议切法 |
|------|----------|
| 底部右侧少女 + 猫 + 花草 | 可作为回忆页装饰组合。 |
| 概览卡图标 | 可临时裁 suitcase/sign/pin/globe，但更推荐用 Iconify 或重新生成统一透明图标。 |
| 回忆图片横滑缩略图 | 可矩形裁切成 WebP。 |

不适合切：

- 折线图、环图、柱状图、雷达图。
- 数字、排行文字、筛选按钮。

所有图表都应该由 ECharts 使用真实数据渲染。

## 如果使用命令行裁剪

安装 ImageMagick 后，可以用下面模板裁 raw crop：

```bash
magick "prd/v8.0/落地页.png" -crop WIDTHxHEIGHT+X+Y "apps/web/src/assets/v8/raw-crops/landing-hero-girl.raw.png"
```

坐标含义：

```text
-crop 宽x高+左上角X+左上角Y
```

例如，先在 Figma/Photoshop 里读出切片框的 x/y/w/h，再填进命令。

不要直接用命令行批量抠透明背景。命令行适合裁 raw crop，复杂透明边缘仍建议人工检查。

## 自动抠图后检查清单

每个透明素材导出前检查：

- [ ] 透明背景干净，没有白色矩形底。
- [ ] 发丝、猫耳、花草边缘没有明显锯齿。
- [ ] 没有把页面文字、按钮、图表误切进来。
- [ ] 画布四周有足够留白，hover 放大不会裁边。
- [ ] 在白色、粉色、深紫色背景上都没有明显脏边。
- [ ] 文件名符合 `ASSET-MANIFEST.md`。
- [ ] 体积合理：大角色尽量小于 500KB，小 pin 尽量小于 80KB。

## 最现实的复原策略

如果只从这 5 张 PNG 硬切，能做到 **70%-85% 接近**，但角色边缘和背景残留会限制上限。

想接近 **90%+**，建议：

1. 先按本指南切 P0 素材。
2. 对边缘不干净的角色和樱花，用 `transparent-assets-prompt.md` 重新生成透明素材。
3. 用代码复原所有 UI、地图、日历和图表。
4. 在浏览器截图中和设计稿逐屏对照，微调尺寸、间距、色彩和阴影。

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tag inner gaps, sparkle offsets |
| sm | 8px | Compact element spacing, tag sticker gaps |
| md | 16px | Default card inner grouping, mobile card padding minimum |
| lg | 24px | Journal stream row gap, card padding on desktop |
| xl | 32px | Header-to-stream spacing, major card clusters |
| 2xl | 48px | Desktop journal line left gutter and state panel breaks |
| 3xl | 64px | Page-level breathing room inside the authenticated shell |

Exceptions: Icon-only management trigger and journal empty/login CTA must keep at least `44px` touch target. Star nodes may render visually at `40px` but must sit in a reserved `48px` timeline column so text never overlaps the node.

## Typography

Phase 46 uses exactly four sizes and two weights in the journal surface. Existing shell tokens may keep their inherited weights, but new journal UI should not introduce extra text sizes or weights.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.4 |
| Heading | 24px | 600 | 1.2 |
| Display | 40px | 600 | 1.1 |

Usage rules:
- Card title uses Heading only when it is the place name; date, badges, tags, and management labels use Label.
- Summary text uses Body and clamps to two lines on desktop and three lines on mobile.
- Do not use viewport-scaled font sizes inside cards, badges, buttons, menus, or state panels.

| Accent (10%) | `#F75A9B` primary, with `#8B6FEF` and `#5EA7F2` only in timeline gradient/node variants | Glowing vertical line, star node fill/glow, active journal nav icon, empty/login CTA, focus ring |

## Phase-Specific Visual Contract

Visual authority: `prd/v8.0/UI/旅途手帐.png` controls atmosphere, glowing vertical line, star nodes, card rhythm, and postcard thumbnail placement. The mockup's `添加新旅行` button and right-side favorite/heart controls are excluded and must not be copied as interactive, disabled, decorative text, or future-placeholder UI.

Page layout:
- Keep the real user-facing route `/journal`; do not revive `/timeline` compatibility.
- Use a full-height authenticated-shell page with a soft glass journal panel, not a landing page.
- The main populated state is a vertical journal stream with a reserved timeline column and reading cards to the right on desktop.
- Mobile layout keeps the timeline column visible but compressed: fixed node column first, card content second, `min-w-0` on text containers, no absolute node overlay on titles.
- Header uses the title `旅途手账`, one short support sentence, and breathing room in the upper-right. No stats pills, add buttons, favorite controls, or return-map utility buttons in populated header.

Journal stream:
- Vertical line is a CSS gradient glow using pink to purple to sky blue, with a blurred halo behind a crisp 2px center line.
- Each entry has one decorative star node aligned to the card's first text block. Node variants may rotate through pink, purple, and blue from deterministic record fields.
- Cards use white glass surfaces, `var(--shadow-float)`, soft frame borders, and `28px` radius consistent with current v8 tokens.
- Card rhythm should alternate subtle vertical spacing only; do not alternate card alignment so aggressively that scanning dates becomes harder.

Card information hierarchy:
- Reading-first order: date, place name, natural location path, one `旅行摘记` summary, tag stickers, low-noise repeat badge, decorative postcard thumbnail.
- Date is visually prominent but smaller than the place name; repeat badge copy is `第 N 次 / 共 M 次` and sits near the date or top card corner.
- Location path is a single natural line such as `中国 · 广东 · 地级市` or `日本 · 京都府`; do not split country/region/type into table-like fields.
- Summary uses the first meaningful note line. If notes are empty, use `这段旅途还没有写下摘记`.
- Tags render as small sticker chips and wrap within the card. Limit initially visible tags to three; use `+N` only if needed to avoid overflow.

Postcard thumbnails:
- Thumbnails are deterministic decorative illustrations, not user photos or uploads.
- Use a stable mapping from fields such as `placeId`, `parentLabel`, `regionSystem`, or `typeLabel`; never use list index, random values, or current date.
- Variants should read as soft landscape postcards: clouds, starlight, city silhouettes, mountains, sea, skyline, shrine/temple, or river scenery.
- Thumbnail elements are non-interactive and hidden from assistive tech with `aria-hidden="true"` or image `alt=""`.

## Interaction Contract

States:
- Restoring state shows Yume Kawaii skeleton cards aligned to the future journal stream and uses `aria-live="polite"`.
- Anonymous state keeps the current auth flow and uses CTA `立即登录`.
- Empty state uses the same visual language as the journal surface and only navigates to `/map` with `去世界足迹留下足迹`.
- Error state, if a reachable journal-local error exists, uses the copy above, soft destructive tint, and a non-destructive recovery action to retry or return to `/map`.

Management actions:
- Edit/delete remain available but move to a quiet management area: a shadcn-vue Dropdown Menu trigger or compact reveal control near the card top-right.
- Management area contains only `编辑` and `删除`; no details panel, no favorite action, no add action, no share/upload action.
- Edit preserves inline replacement with `TimelineEditForm`, including date conflict warnings, notes, tags, submit, cancel, and store behavior.
- Delete preserves `ConfirmDialog` and destructive semantics. The destructive action is visually quiet until confirmation.

Motion:
- Use transform and opacity for hover, entrance, shimmer, and node glow. Do not animate layout-affecting properties.
- Hover lift is at most `translateY(-2px)` for cards and must not resize the card.
- `prefers-reduced-motion: reduce` disables shimmer/float/entrance and keeps only instant state changes.

Accessibility:
- Star nodes, sparkles, glow lines, and thumbnails are decorative and hidden from assistive tech.
- Every interactive control has visible focus and an accessible name.
- Dropdown/menu items are keyboard reachable through local shadcn-vue primitives.
- Text must not be hidden by thumbnails or nodes at 320px mobile width; reserve layout tracks instead of overlaying content.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| travel record data -> decorative thumbnail | Real private visit data selects a visual variant but must not imply public photos or uploads. |
| notes/tags -> rendered summary | User-entered notes and tags must stay text-rendered and not become HTML. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-46-05 | Spoofing | `JournalPostcardThumb.vue` | mitigate | Render thumbnails as `aria-hidden` CSS decorations with no photo/upload copy and no interactive semantics. |
| T-46-06 | Information Disclosure | `journal-thumbnails.ts` | mitigate | Use only local `TimelineEntry` fields and no external network, storage, or image lookup. |
| T-46-07 | Tampering | `getJournalSummary()` | mitigate | Return plain strings consumed by Vue interpolation; do not introduce `v-html`. |
| T-46-08 | Denial of Service | `getJournalPostcardVariant()` | accept | Hash input is short record metadata already present in memory; no unbounded loops beyond field string length. |
</threat_model>

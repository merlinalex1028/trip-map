# Phase 42 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by `$gsd-ui-phase`, verified against Phase 42 context.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | `shadcn-vue` generated local primitives |
| Preset | `yume-kawaii-soft-pastel-glass` |
| Component library | shadcn-vue local components; use the primitive dependency generated by the shadcn-vue CLI |
| Icon library | `KawaiiIcon` semantic wrapper: `prd/v8.0/切图` assets first, locally registered Iconify fallback only |
| Font | `Nunito Variable`, `Noto Sans SC`, `PingFang SC`, `Hiragino Sans GB`, `Microsoft YaHei`, sans-serif |

**Authority:** `prd/v8.0/UI/*.png` defines the visual target. `prd/v8.0/UI/世界足迹.png` is authoritative for map mood and popup shape, except its bottom left-sidebar illustration; that sidebar illustration must follow `旅途回忆` / `旅途手帐` and available cutouts instead.

**Phase boundary:** This phase establishes reusable primitives and design tokens only. It must not migrate existing business flows such as `AuthDialog`, `ConfirmDialog`, `TripDateForm`, or map popup record controls.

## Spacing Scale

Declared values must remain multiples of 4 and map back to `apps/web/src/styles/tokens.css`.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, tiny badge internals, separator offsets |
| sm | 8px | Compact control gaps, calendar day internals, nav icon/text gap |
| md | 16px | Default component padding, form field rhythm |
| lg | 24px | Card padding, dialog section padding, showcase section gaps |
| xl | 32px | Large card/dialog padding, sidebar inner padding |
| 2xl | 48px | Major showcase groups, page shell gutters |
| 3xl | 64px | Wide desktop hero/showcase breathing room only |

Exceptions: `--radius-pill: 999px` is allowed for pills; icon cutouts may use intrinsic aspect ratio but must sit inside fixed-size layout boxes.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.5 |
| Label | 14px | 600 | 1.4 |
| Heading | 24px | 700 | 1.2 |
| Display | 40px desktop / clamp down on mobile | 800 | 1.1 |

Additional rules:

- Primary UI text uses deep indigo/purple ink, never pure black.
- Do not use negative letter spacing. Keep letter spacing at `0` unless matching existing small uppercase label treatment.
- Data numbers in charts/showcase use tabular numerals where available.
- Headings in compact cards/dialogs must stay card-scale; hero-scale display type is reserved for landing/page-level compositions in later phases.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8FD` / `#FAFAFF` | Page backgrounds, showcase canvas, glass surface base |
| Secondary (30%) | `#F2E8FF`, `#EAF6FF`, `#FFF0F7` | Cards, sidebar active backgrounds, panel washes |
| Accent (10%) | `#F75A9B` | Primary CTA, selected calendar day, active marker, key chart line/segment |
| Supporting accent | `#8B6FEF`, `#5EA7F2`, `#7ED9B6`, `#F5A354` | Icon/charts/status palette, not primary CTA competition |
| Ink strong | `#25146F` | Headings and key labels |
| Ink muted | `#6F5B99` | Body, subtitles, chart axis labels |
| Frame | `#E8DDF6` | Soft borders and dividers |
| Destructive | `#C86464` | Destructive actions only |

Accent reserved for: primary buttons, selected calendar date, active nav item icon/fill, active chart emphasis, and selected showcase states. Do not tint every interactive element pink.

Color contract:

- shadcn-vue neutral defaults must be replaced with this Yume Kawaii palette.
- Use translucent white/pink/lavender glass surfaces with soft borders, not gray card chrome.
- No neon glows. Shadows must be diffuse and tinted softly by the surface hue.
- Gradients are allowed only where already part of the v8 language: pink CTA, soft panel wash, chart fills, and gentle decorative backgrounds.

## Surface, Radius, and Shadow

| Surface | Radius | Border | Shadow |
|---------|--------|--------|--------|
| Button / pill control | `999px` or 18-22px | translucent pink/lavender frame | `--shadow-button` style inner highlight + small lift |
| Card / showcase tile | 24-32px | `1px` soft lavender/white | low diffuse shadow, no heavy drop shadow |
| Dialog / popover | 32px | translucent lavender frame | stage-level soft shadow, backdrop blur |
| Calendar grid | 28-32px container, circular selected day | very light frame | minimal; selected day carries accent |
| Sidebar item | 18-24px | none or soft frame | active item may use soft wash only |
| Chart card | 24-28px | very light frame | subtle shadow; data readability wins |

Glass contract:

- Use white or pastel translucent fills with inner refraction borders where useful.
- Avoid large animated blur/backdrop-filter surfaces; static blur is acceptable for dialogs and panels.
- Do not nest UI cards inside larger decorative cards unless the inner element is an actual repeated item or overlay primitive.

## Component Contracts

### shadcn-vue Primitives

Phase 42 must install/generate and theme:

- `Button`
- `Card`
- `Dialog`
- `Popover`
- `Calendar`
- `Tabs`
- `Sidebar`
- `Dropdown Menu`
- `Skeleton`
- `Scroll Area`

Default variants must already look like v8. Do not ship generic shadcn neutral black/white/gray as the default style.

Required states:

- Default
- Hover/focus-visible
- Active/pressed
- Disabled
- Loading or skeleton where applicable
- Error/destructive where applicable

Interaction requirements:

- Dialog and Popover must rely on accessible primitives for focus, escape handling, and outside click behavior.
- Icon-only buttons must have `aria-label`.
- Calendar selection must be keyboard reachable and show visible selected/focus states.
- Dropdown and Sidebar items must have clear active and disabled styling.

### `/__ui` Showcase

`/__ui` is a developer validation surface, not a user feature.

- Route is available only under `import.meta.env.DEV`; production redirects to `/`.
- It displays all Phase 42 primitives in state matrices.
- Dialog, Popover, Dropdown, and Calendar examples must be operable.
- It includes a `BaseChart` demo using clearly labeled demo options, not real travel data.
- It includes `KawaiiIcon` examples for semantic names and cutout/Iconify fallback behavior.
- It must remain a thin route-level view; move showcase sections into focused components if the route becomes large.

### `KawaiiIcon`

Contract:

- Public API is semantic, e.g. `name="map" | "journal" | "memories" | "calendar" | "star" | "camera" | "badge" | "pin"`.
- Page code does not pass raw Iconify ids or asset filenames.
- Cutout assets from `prd/v8.0/切图` are preferred when available; only copied assets go under `apps/web/src/assets` with English kebab-case names.
- Iconify fallback icons must be locally registered/whitelisted and render without runtime network fetch.
- Icons sit in stable square boxes (`size-*` or equivalent fixed dimensions) so loading, hover, and label changes do not shift layout.

### `BaseChart`

Contract:

- Accepts ECharts `option` and explicit state props; does not read Pinia stores or APIs in Phase 42.
- Handles `loading`, `empty`, `error`, fixed/min dimensions, and resize behavior.
- Uses central on-demand ECharts registration under a `lib/charts` style module.
- Required chart capabilities for future Phase 47: line, pie/donut, bar, radar, tooltip, grid, legend, title/label basics, and canvas renderer.
- Theme follows `旅途回忆`: pink primary, lavender, sky blue, mint, warm orange, very light grid, deep indigo labels, glass-like tooltip.

## Motion Contract

| Motion | Value |
|--------|-------|
| Interaction feedback | 140-180ms |
| Entrance / reveal | 180-240ms maximum, CSS-only unless later phase explicitly needs JS motion |
| Animated properties | `transform`, `opacity` |
| Reduced motion | Required via `prefers-reduced-motion` |

Rules:

- No custom cursor.
- No layout-property animation (`width`, `height`, `top`, `left`, `margin`, `padding`).
- No perpetual animation in Phase 42 primitives except subtle skeleton shimmer; later decorative assets can decide per page.
- Hover/active feedback should be tactile but modest: tiny translate/scale, never bouncing layout.

## Accessibility Contract

- Every interactive primitive must have visible focus states.
- Dialog and popover examples must preserve focus management through the underlying primitive.
- Icon-only controls require `aria-label`.
- Loading and error states should be announced with appropriate semantic containers when used in real components.
- Calendar days must not rely on color alone; selected/focused states need shape or border changes.
- Text must remain readable against translucent/glass surfaces at desktop and mobile sizes.
- Do not use text inside decorative cutout images as the only accessible label.

---

## Responsive Contract

- Mobile layouts collapse to single column below `768px`.
- Do not use `h-screen`; use `min-h-[100dvh]` or content-driven sizing for full-height contexts.
- Fixed navigation or showcase controls must respect safe-area insets when later implemented.
- Component state labels/buttons must have stable dimensions so hover, loading, and dynamic labels do not shift layout.
- Showcase examples should avoid horizontal scrolling except intentional `Scroll Area` demos.

---

## Asset Contract

- Phase 42 does not bulk-copy `prd/v8.0/切图`.
- Later phases must inspect `prd/v8.0/切图` before recreating decorative characters, icons, signs, backgrounds, paw/star stickers, or sidebar illustration assets.
- Only used assets are copied to `apps/web/src/assets`.
- Copied filenames must be English kebab-case, e.g. `landing-hero-girl.png`, `sidebar-travel-girl.png`, `paw-badge-pink.png`.
- Keep a mapping in implementation notes or code comments only when the original source filename is unclear.
- Known exception: do not use the bottom left-sidebar illustration in `prd/v8.0/UI/世界足迹.png` as authoritative; use `旅途回忆` / `旅途手帐` references for that area.

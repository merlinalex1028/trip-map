## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| page props -> icon renderer | Callers pass semantic icon names into a component that renders SVG. |
| local registry -> SVG output | Static icon bodies become rendered SVG through Iconify. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-42-01 | Tampering / XSS | `KawaiiIcon`, `registry.ts`, `semantic-icons.ts` | mitigate | Public API accepts only `KawaiiIconName`; icon ids and SVG bodies live in a local static whitelist; tests and grep checks block runtime Iconify API strings. |
| T-42-04 | Tampering | icon dependencies | mitigate | Plan 01 pins `@iconify/vue@5.0.1`; this plan imports only local APIs and uses typecheck. |
| T-42-03 | Information Disclosure | `/__ui` icon examples | transfer | Icon examples are integrated only in Plan 05, where `/__ui` is guarded by `import.meta.env.DEV`. |
</threat_model>

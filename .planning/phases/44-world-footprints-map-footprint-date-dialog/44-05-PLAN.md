## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| popup snapshot -> store illuminate | 地点身份和日期 payload 进入账号旅行记录写入流程 |
| auth session -> record write | 当前浏览器会话决定是否允许调用 records API |
| store result -> dialog/page feedback | 保存结果被映射成 Dialog inline error 或 page/global notice |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-44-16 | Tampering | `LeafletMapStage.vue` snapshot submit | mitigate | `submitFootprintDate` 只从 `footprintPlaceSnapshot` 取 place fields，集成测试覆盖 active point 变化后仍保存 place A |
| T-44-17 | Elevation of Privilege | anonymous submit path | mitigate | anonymous submit 调用 `openAuthModal('login')`，不调用 `mapPointsStore.illuminate` 或 records API |
| T-44-18 | Repudiation | save feedback | mitigate | Store 返回 `saved/failed/unauthorized/stale` 状态并设置明确中文 notice，Dialog 对失败保留 inline error |
| T-44-19 | Tampering | session-boundary stale writes | mitigate | Preserve existing `boundaryVersionAtStart` / `hasSessionBoundaryChanged` guard and return `{ status: 'stale' }` |
| T-44-20 | Denial of Service | submitting state | mitigate | `isFootprintSubmitting` disables duplicate submit/close-confusing actions and restores state in `finally` |

No high-severity threats identified for this integration plan. Relevant mitigations cover authentication, data integrity, and focus/state safety.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| authenticated route -> shell | Authenticated page content is wrapped with current user shell state. |
| shell logout -> auth store/backend | Logout mutates cookie-session state through the existing auth store and backend endpoint. |
| App foreground events -> auth bootstrap | Focus/visibility refreshes fetch authenticated snapshots only when already authenticated. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-43-08 | Information Disclosure | App public route branch | mitigate | Render `AuthenticatedAppShell` only when `route.meta.requiresAuth === true`; `/` landing is direct public route content. |
| T-43-09 | Repudiation | Logout action | mitigate | Logout uses existing `logout()` store action and then routes to `/`; keep existing global logout notice behavior. |
| T-43-10 | Spoofing | Sidebar identity | mitigate | Sidebar username comes from `currentUser`; avatar is decorative/default only and no upload or user-supplied image URL is accepted in this phase. |
| T-43-11 | Elevation of Privilege | Old topbar navigation | mitigate | Remove authenticated route navigation from `AuthTopbarControl`; primary navigation is the protected shell only. |
</threat_model>

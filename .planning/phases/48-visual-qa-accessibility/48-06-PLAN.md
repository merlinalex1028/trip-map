| Boundary | Description |
|---|---|
| developer shell to seed script | Environment variables and CLI flags decide whether DB writes occur. |
| seed script to database | QA seed can create or update auth credentials and records. |
| browser user to auth modal | Sensitive credential input persists in a globally mounted component if not cleared. |
| browser user to date dialog | Date shortcut selection becomes persisted record payload. |
| browser user to authenticated shell | Logout control changes authenticated session state. |
| browser user to Leaflet map | Click handler triggers canonical recognition requests. |
| verification evidence to release decision | Docs can misclassify DB environment failure as product success. |

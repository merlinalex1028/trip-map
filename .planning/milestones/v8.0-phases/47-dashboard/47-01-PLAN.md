- D-07: the profile payload supports a gentle memories profile with labels and explanations, not a professional rating report.
- D-09, D-10, D-11, D-12: this plan returns a deterministic Top 5 repeat-visit payload with recent-date tie breaking.
- D-10: popular footprint tie-breaking sorts the more recent usable visit date first after repeat visit count.

- D-13, D-14, D-15, D-16: this plan returns recent dated real-record postcard seeds only; visual browsing behavior lands later.
- D-14: postcard seed selection prefers the most recent dated travel memories.
- D-15: each postcard seed exposes lightweight place and date context through display name, parent label, and start date.
</decision_traceability>

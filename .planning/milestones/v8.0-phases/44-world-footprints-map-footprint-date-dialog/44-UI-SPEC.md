# Phase 44 — UI Design Contract

> Visual and interaction contract for 世界足迹地图与留下足迹日期弹窗. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Scope

Phase 44 upgrades the authenticated `/map` route into the v8 `世界足迹` experience while preserving the existing Leaflet recognition and record-write chain.

In scope: map stage styling, star/footprint marker treatment, map-route sidebar visual restoration, unified place-information popup, standalone `留下足迹` date dialog, shortcut date controls, snapshot-safe submit behavior, and local/page-level feedback states.

Out of scope: saveable coverage expansion, journal/memories redesign, new navigation capabilities, collection/favorite UI, photo upload, achievement systems, and a whole-app shell re-architecture.

| Area | Contract |

## Place Popup Contract

`PointSummaryCard` becomes a unified place-information card. It must not render saved-place trip history, latest trip rows, inline date form, `PopupTripRecord`, or any `再留一次` / `再记一次` branch copy.

| Element | Contract |
|---------|----------|
| Badge | `识别结果` for detected preview, `查看地点` for saved/re-opened place, `确认地点` for candidate selection. |
| Place title | Most prominent text in the popup. Use real resolved place name, not coordinates as the primary title when a canonical place exists. |
| Type label | Small pill near title, e.g. country/region/city/admin type. Do not make it larger than the place name. |
| Region subtitle | One concise line or wrapped block with region context such as country/parent region and coordinate fallback if needed. |
| Saved indicator | For saved places, show warm context copy: `这里已经留下过足迹` plus optional count only if already available. Do not show individual trip rows. |
| Primary CTA | Always render `留下足迹` for non-candidate place cards. It opens the standalone date dialog only when the place is saveable and the user is allowed to proceed. |
| Unavailable place | Keep the `留下足迹` button visible but disabled. Show inline explanation: `已识别到这个地点，但当前数据还不满足保存足迹的条件。` |
| Anonymous state | If the auth gate can be reached in context, explain locally: `登录后才能留下足迹。` and route/open existing auth flow according to app behavior. No silent click failure. |
| Candidate mode | Candidate selection remains a separate confirmation flow. Candidate buttons must keep type/subtitle/status and visible recommended state. |

Required hooks:

| Hook | Use |
|------|-----|
| `data-region="point-summary-card"` | Popup card root |
| `data-summary-mode` | `detected-preview`, `view`, or `candidate-select` |
| `data-place-type-label="true"` | Type pill |
| `data-place-subtitle="true"` | Region/subtitle text |
| `data-footprint-cta="true"` | Unified `留下足迹` CTA |
| `data-footprint-unavailable-reason` | Disabled reason container |

## Footprint Date Dialog Contract

Create a standalone `FootprintDateDialog` using local shadcn-vue `Dialog` and `Calendar`. It must feel like a substantial card-style modal, not a lightweight popover or inline form.

| Area | Contract |
|------|----------|
| Header | Title `留下足迹`; description includes the snapshot place name and region context. |
| Visual zone | Use `footprint-dialog-girl.webp` or equivalent local v8 illustration on desktop. Decorative image uses `alt=""` and `aria-hidden="true"`. |
| Place summary | Show snapshot `displayName`, type label, and region subtitle inside the dialog. This must not update if the active map selection changes while the dialog is open. |
| Shortcut dates | Four segmented/pill buttons only: `今天`, `明天`, `本周末`, `其他日期`. Selected shortcut has shape + accent fill, not color alone. |
| Calendar | Full calendar visible on first screen. Do not hide it behind expand/collapse. Calendar selected day syncs with shortcut choice. |
| Optional end date | Allowed but secondary. If exposed, label as `结束日期（可选）` and keep single-day default. |
| Submit | Primary action `保存足迹`; disabled while invalid or submitting; loading copy `正在保存...`. |
| Cancel/close | Secondary action `取消`; Esc/outside close follow Dialog behavior unless submit is in progress. |
| Success | Close dialog after successful save, return focus to `留下足迹` trigger or stable popup title, and show page-level success notice `足迹已保存。` |
| Failure | Keep dialog open, preserve selected date, focus/announce inline error, and show copy from this spec. |

Date semantics:

| Rule | Contract |
|------|----------|
| Default model | Single-day visit first. |
| Payload | Submit `{ startDate: string | null; endDate: string | null }`. |
| Format | Use `YYYY-MM-DD`; `CalendarDate.toString()` from `@internationalized/date` is acceptable. |
| Snapshot safety | Build immutable `FootprintPlaceSnapshot` before opening the dialog. Submit reads the snapshot, never the current `summarySurfaceState`. |
| Weekend shortcut | `本周末` selects the nearest upcoming Saturday as `startDate`; if an optional end date is shown, Sunday may be `endDate`. |

Required hooks:

| Hook | Use |
|------|-----|
| `data-region="footprint-date-dialog"` | Dialog content root |
| `data-footprint-place-name` | Snapshot place name |
| `data-footprint-shortcut` | Shortcut buttons with values `today`, `tomorrow`, `weekend`, `custom` |
| `data-footprint-calendar="true"` | Calendar root/wrapper |
| `data-footprint-submit="true"` | Submit button |
| `data-footprint-cancel="true"` | Cancel button |
| `data-footprint-error="true"` | Inline dialog error |

## State Feedback Contract

Feedback is layered by context. Local, actionable states live inside popup/dialog; broad result states may use the existing page/global notice surface.

| State | Surface | Copy / Behavior |
|-------|---------|-----------------|
| Recognizing click | Map stage | Keep existing recognition status, but style as soft glass notice. Copy: `正在识别地点...` |
| Recognized saveable place | Popup | Show place name/type/region and enabled `留下足迹`. |
| Recognized but not saveable | Popup | Disabled `留下足迹`; reason `已识别到这个地点，但当前数据还不满足保存足迹的条件。` |
| Saved place | Popup | Same place layout; show `这里已经留下过足迹`; CTA remains `留下足迹`. |
| Anonymous user | Popup or dialog entry | `登录后才能留下足迹。` No silent failure. |
| Dialog submitting | Dialog | Disable close actions that would cause double-submit confusion; submit label `正在保存...`; retain visible selected date. |
| Date range invalid | Dialog | Inline alert: `结束日期不能早于开始日期。` |
| Save failed | Dialog + optional page notice | Inline alert: `足迹暂时没有保存成功，请检查网络后重试。` |
| Save succeeded | Page/global notice | `足迹已保存。` Dialog closes and focus returns predictably. |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, focus offset, tiny badge/sticker separation |
| sm | 8px | Type pill internals, shortcut button gaps, compact popup rhythm |
| md | 16px | Popup internal grid, form fields, calendar cell gutters |
| lg | 24px | Map stage padding, popup card padding, dialog section gaps |
| xl | 32px | Dialog outer padding, sidebar visual groups, stage-to-popup breathing room |
| 2xl | 48px | Desktop dialog margins, map composition gutters |
| 3xl | 64px | Wide desktop map-stage breathing room only |

Exceptions: interactive targets must be at least `44px`; authenticated sidebar width remains `280px`; popup target width is `320px` with max `384px`; desktop dialog target width is `960px`; star pin artwork may use intrinsic `96px` or `128px` source images but must render in fixed marker boxes.

## Typography

Use exactly these type roles for new Phase 44 surfaces. Letter spacing is `0`.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 14px | 600 | 1.4 |
| Body | 16px | 400 | 1.5 |
| Heading | 24px | 600 | 1.2 |
| Display | 32px | 600 | 1.1 |

Rules:

- Place names use `Heading` in popup and `Display` only in the dialog header/place summary when space allows.
- Body and helper text use `#6F5B99`; primary text uses `#25146F`.
- Do not introduce weights beyond `400` and `600` in new Phase 44 components.
- Do not use viewport-scaled font sizes for popup, dialog, sidebar, or marker labels.
- Long place names wrap without clipping; controls must not resize horizontally on loading or selected states.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#FFF8FD` with `#FAFAFF` | Page/map route background, map-stage base, dialog backdrop wash |
| Secondary (30%) | `rgba(255, 255, 255, 0.78)`, `#F2E8FF`, `#EAF6FF`, `#FFF0F7` | Popup, sidebar, date dialog panels, shortcut inactive states, calendar surface |
| Accent (10%) | `#F75A9B` | `留下足迹` CTA, `保存足迹` CTA, selected shortcut, selected calendar day, active/pending star marker, focus ring |
| Destructive | `#C86464` | Failed submit/error text and destructive copy only |

Accent reserved for: popup primary CTA, dialog primary submit, selected shortcut, selected calendar date, pending/active star marker, focus ring, and one or two small sparkle accents. Do not apply accent to every marker, every sidebar icon, all links, or all labels.

Supporting colors: use `#5EA7F2` for saved/confirmed footprints, `#8B6FEF` for deep lavender emphasis, `#7ED9B6` for success/supporting status, and `#F5A354` for warm weekend/illustration accents. These colors must not compete with the pink primary CTA.

## Accessibility Contract

| Concern | Contract |
|---------|----------|
| Popup semantics | `MapContextPopup` remains `role="dialog"` with `aria-modal="false"` and a focusable hidden title. Opening a popup moves focus to the title or first meaningful control. |
| Dialog semantics | `FootprintDateDialog` uses shadcn-vue/Reka Dialog with title, description, modal focus trap, Escape close, outside close, and focus return. |
| Calendar | Calendar days are keyboard reachable. Selected/focused days use shape/border plus color. |
| Buttons | Icon-only marker/buttons require `aria-label`; CTA buttons are real `<button type="button">` or submit buttons as appropriate. |
| Disabled CTA | Disabled `留下足迹` must have adjacent visible reason text, not only a disabled title tooltip. |
| Error announcement | Dialog save/range errors use `role="alert"` or equivalent live announcement. |
| Success announcement | Page/global success notice is announced without stealing focus from the next logical surface. |
| Decorative images | Popup/dialog/sidebar illustrations use `alt=""` and `aria-hidden="true"`. Meaningful place and date text is real DOM. |
| Reduced motion | Under `prefers-reduced-motion`, disable marker pulse, hover lift, floating/breathing effects, and long transitions while keeping focus/color states. |

## Forbidden Patterns

- Do not replace Leaflet or bypass the canonical resolve/confirm chain.
- Do not render the date form inline in `PointSummaryCard`.
- Do not read the current active map selection during dialog submit; use the opening snapshot.
- Do not show saved-place trip lists, latest trip rows, `PopupTripRecord`, or record management controls inside the map popup.
- Do not use `点亮`, `已点亮`, `再记一次`, `保存去访`, or `取消点亮` in new Phase 44 map-facing copy.
- Do not show a clickable `留下足迹` path for non-authoritative/unavailable places.
- Do not add favorites, collection buttons, upload/photo controls, achievements, or new sidebar navigation.
- Do not import assets directly from `prd/v8.0/切图`.
- Do not rely on baked PNG text for titles, CTAs, date labels, place names, or errors.

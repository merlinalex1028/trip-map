## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Map popup -> date dialog | User intent crosses from map popup into a modal date-entry flow. |
| Chart data -> chart UI | Server-authoritative stats are transformed into chart options and rendered by ECharts. |
| Status feedback -> assistive technology | Loading, error, and save feedback must remain available to keyboard and screen-reader users. |

</threat_model>
